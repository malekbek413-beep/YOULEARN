# YOULEARN

منصة تعليمية عربية تجريبية بواجهة RTL ومتجاوبة مع الموبايل والكمبيوتر.

## المميزات
- لوحة رئيسية وإحصائيات وأهداف تعلم.
- كتالوج كورسات مع البحث والتصفية.
- دروس قصيرة وتسجيل الدروس المكتملة.
- اختبار تفاعلي وتصحيح فوري.
- متابعة التقدم والملف الشخصي.
- حفظ محلي عبر localStorage.

## التشغيل والنشر
مشروع static لا يحتاج build. افتح index.html أو انشر المستودع على Vercel كـ Other مع مجلد إخراج `.`.

## حدود النسخة
هذه MVP ببيانات تعليمية تجريبية. لا يوجد حالياً تسجيل دخول آمن أو قاعدة بيانات أو مزامنة بين الأجهزة؛ بيانات التقدم محفوظة في المتصفح الحالي فقط.
